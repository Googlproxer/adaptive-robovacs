# Adaptive RoboVacs v1.4.3

Version 1.4.3 completes mop-capability discovery for robots whose vendor mode
selector loads independently of the normalized profile snapshot.

## Fix

- Adapter entity evidence now carries transient same-device select options.
- The generic and Roborock capability resolvers verify an explicit selector
  advertising both vacuum and mop operations even when the profile heuristic
  did not classify it during the same discovery pass.
- A verified Roborock without water telemetry therefore exposes mop programs
  through the fail-closed one-hour confirmation path.

The select entity IDs and raw vendor values remain transient: they are not
stored, logged, exposed in Repairs, or projected to dashboard status.

## Validation and deployment

The complete Python and frontend contract suites pass, including a regression
using the operation values advertised by a no-water-telemetry Roborock. Install
`v1.4.3` through HACS and restart Home Assistant. No Store migration or entity
ID change is introduced beyond v1.4.0.
