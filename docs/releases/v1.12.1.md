# Adaptive RoboVacs v1.12.1

## User-visible changes

- The Floor plan dashboard view presents its Ground and Upper plan cards at
  the full available page width.
- Every floor-plan canvas now has an 800px minimum height, giving the editor
  enough working space to arrange rooms and occupancy-sensor markers.
- For the first minute after Home Assistant starts, new scheduled and
  dashboard-manual cleaning requests are safely rejected while occupancy
  providers restore their live states.

## Migration and safety

- The startup settling period is non-bypassable; Party Mode and observe-only
  rules remain unchanged. Existing saved floor-plan diagrams remain untouched.

## Validation

- `python -m unittest discover -s tests -v`
- Python compilation of every integration module
- `node --check` and `node --test tests/test_dashboard.mjs`
- Confirmed served and standalone dashboard JavaScript copies are byte-identical.
