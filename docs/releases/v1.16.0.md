# Adaptive RoboVacs v1.16.0

Scheduled cleaning now respects occupied neighbouring rooms through saved
floor-plan links. An occupied bedroom can hold the hallway while an unlinked
living room remains eligible.

- Each room has **Adjacency protection: Off / Night only / Always**, defaulting
  to Night only. The setting governs that room's own cleaning.
- Global **Adjacency night start/end** controls default to **23:00–09:00** in
  Home Assistant's timezone, independently of the Night cleaning-period preset.
- Occupied and unresolved neighbours block scheduled vacuum/mop stages. A room
  without sensors remains non-blocking. Status and robot previews name blockers.
- Safety checks run before each scheduled stage and again after dispatch
  preparation. Running stages finish; manual Clean retains its override. Settings
  and floor-plan saves refresh previews without dispatching.

## Migration

Schema 18 preserves existing floor-plan links, jobs, recovery state and history
while adding night-only defaults. Existing links begin protecting rooms after
the new backend loads. Review the controls after restarting. See the
[migration guide](https://github.com/Googlproxer/adaptive-robovacs/blob/v1.16.0/docs/migration-v1.16.0.md).

Install the exact **v1.16.0** tag through HACS and validate Home Assistant's
configuration. This deployment is requested **without a Home Assistant restart**.
The new backend and controls become active after a later user-controlled restart.
No cleaning commands, integration reloads or restarts are part of this deployment.
