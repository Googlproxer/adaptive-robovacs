# Adaptive RoboVacs 1.14.0 — unreleased

## Changes

- Remove bedroom-transit scheduling rules: the all-bedrooms occupancy gate,
  separate daytime window, and special unresolved-occupancy exclusion.
- Remove transit time selectors, configuration/global settings, and the
  `bedroom_transit` room schedule attribute.
- Clean obsolete settings from existing config entries and valid scheduler
  state, and retire only the owning entry's obsolete select registry records.
- Update current setup, architecture, and future feature plans to use room-local
  occupancy without carrying forward the removed feature.

Ordinary bedroom classification, saved room settings, manual-clean behavior,
Party Mode, observe-only mode, startup settling, and robot readiness rules remain.
Room adjacency is separate future work.

## Migration

This release removes public controls and attributes. See
[the migration guide](../migration-v1.14.0.md) for removed identifiers, consumer
cleanup, and schema-16 preservation. Deleting the obsolete HA label also removes
its assignments and can change scheduling in an older installed version.

## Validation and deployment

Local validation on Windows with Python 3.14.6:

- Pytest: 426 tests and 343 subtests passed; total coverage 95.83% (95% required).
- Unittest compatibility: 426 tests passed.
- Dashboard tests: 24 passed.
- Ruff formatting/lint and strict mypy: passed.
- Compilation of every top-level integration Python module: passed.
- Dashboard JavaScript and brand icon byte-parity checks: passed.

These results cover the bedroom-transit removal. The 1.14.0 release remains open
for additional work; rerun the complete validation suite against the combined
changes before publishing. GitHub Actions has not run for this removal yet.

No tag, GitHub Release, HACS install, integration reload, or Home Assistant restart
has been performed for this pending release. Publishing and deployment remain
deferred; follow the approved release procedure when requested.
