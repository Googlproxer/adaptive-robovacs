# Adaptive RoboVacs 1.14.0 — unreleased

## Changes

- Add persistent room Repairs for robot errors during integration-owned,
  single-room scheduled and dashboard cleaning occurrences.
- After ten continuous seconds of docked, terminal-ready observations with no
  current error, detach the interrupted job and release its matching robot
  hold. The affected room remains blocked while other eligible rooms can clean.
- Repair confirmation permits only the unfinished stage to retry through
  normal scheduling. It preserves completed stages, passes, profiles, and robot
  assignment, clears manual bypasses, and sends no physical commands. Stale
  confirmations cannot clear newer episodes, and other faults remain intact.
- Preserve physical resume before detachment and confirmed completion, without
  treating an unresolved error's return to dock or elapsed time as success.
- Discover normalized robot-error evidence through adapter registry metadata,
  with safe descriptions and conservative handling of unavailable or ambiguous
  configured diagnostics.
- Advance the scheduler payload to schema 17 and reconstruct matching legacy
  error holds using fresh observations. Ambiguous jobs retain their robot hold
  and receive an explicit robot Repair.
- Update the Home Assistant requirement and test pin to 2026.9.1, its test
  plugin to 0.13.364, and the CI Python pin to 3.14.7.
- Remove bedroom-transit scheduling rules: the all-bedrooms occupancy gate,
  separate daytime window, and special unresolved-occupancy exclusion.
- Remove transit time selectors, configuration/global settings, and the
  `bedroom_transit` room schedule attribute.
- Clean obsolete settings from existing config entries and valid scheduler
  state, and retire only the owning entry's obsolete select registry records.
- Update current setup, architecture, and future feature plans to use room-local
  occupancy without carrying forward the removed feature.

Ordinary bedroom classification, saved room settings, manual-clean behavior,
Party Mode, observe-only mode, startup settling, and robot readiness rules remain.
Room adjacency is separate future work.

## Migration

This release removes public controls and attributes. See
[the migration guide](../migration-v1.14.0.md) for removed identifiers, consumer
cleanup, the validated schema-16-to-17 migration, and recovery confirmation.
Deleting the obsolete HA label also removes its assignments and can change
scheduling in an older installed version.

vacuums. Check the GitHub Actions result for the final release commit before
