# Adaptive RoboVacs 1.11.4

## Fixed

- Every scheduler-owned Roborock mop stage now requests a mop to revalidate an
  asserted water-shortage sensor when the mop and water box are still attached.
  This accommodates request-driven water telemetry that otherwise remains stale.
- Missing, unavailable, unknown, incomplete, or detached water telemetry still
  blocks mopping. Dashboard manual mops keep their existing water safeguards.
- A command accepted by Rob continues as normal; a command that does not start
  remains subject to the existing robot fault and start-confirmation handling.

## Validation and deployment

Run the complete unit suite and Python compilation checks before release. Install
the exact HACS version and restart Home Assistant only after both vacuums are
idle.
