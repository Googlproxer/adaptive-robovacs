# Adaptive RoboVacs v1.15.1

## Fixes

The v1.15.0 room dashboard could omit Next clean and throw
`this._row.setConfig is not a function`. The timestamp row now assigns the
native Home Assistant generic row's reactive `config` property. Countdown
formatting, timer cleanup, and the exact-timestamp details action are retained.

Populated Kiosk schedules could show configuration errors. Their final template
result was JSON text containing lowercase booleans, which Home Assistant did
not convert into a native list. Auto-entities interpreted that text as entity
fragments. The template now returns the native card list directly; individual
Bubble Card text literals still use JSON escaping.

Existing Kiosk installations must update the final template expression from
`{{ result.rows | to_json }}` to `{{ result.rows }}` in each robot popup.
See the [dashboard template contract](../dashboard.md).

This patch changes presentation only. Sensor identities, timestamp values,
scheduling behavior, recorder history, and Store schema 17 remain unchanged.

## Validation

The regression tests reproduced both production failures before the fixes.
The frontend mock now follows the native row interface, and Kiosk tests inspect
Home Assistant's actual template subscription result, including native boolean
configuration fields, safe text escaping, ordering, and empty/unavailable states.

- 434 Python tests passed with 96.26% coverage (95% required).
- All 28 dashboard tests passed.
- Ruff formatting/lint, strict mypy, unittest compatibility, root and recursive
  compilation, dashboard byte parity, and icon parity passed.
- Live MCP template evaluation returned native lists for both populated robot
  popups. Readback confirmed only the two final template expressions changed.

The running Home Assistant Core and current stable release were both 2026.9.1
on 8 September 2026. Public PyPI and official GitHub Actions release metadata
confirmed the existing compatible test and CI pins remain current, as documented
for v1.15.0. No live Home Assistant upgrade is included.

## Deployment

After CI passes, install the exact `v1.15.1` HACS tag, validate Home Assistant's
configuration, apply the targeted Kiosk template corrections using a fresh
dashboard hash, and update the served dashboard resource to `?v=1.15.1`.

Do not restart Home Assistant or reload the integration. This patch updates the
served JavaScript and live dashboard templates; reload the browser to load the
corrected module. Any integration restart remains under the user's control.
