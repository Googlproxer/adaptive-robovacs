# Adaptive RoboVacs v1.9.0

## Added

- Optional non-root Q10/B01 retained-map recovery guard for compatible
  Roborock runtimes. It stores server-side snapshots of robot-retained map
  frames and previews, but never imports raw map files or starts a clean.
- Read-only map list and capture services, a per-robot recovery status sensor,
  capture button, preview selector, and dashboard recovery controls.
- A durable manual-verification scheduler hold around retained-map activation.
  It remains until manual relocalization and explicit mapping preflight have
  completed.

## Deployment notes

- The feature reuses Home Assistant's existing Roborock authentication and
  MQTT connection. It needs no root access, SSH, local broker, or second login.
- MapLoader remains out of scope because it requires filesystem access on the
  robot. This is recovery for maps the robot still retains, not raw-map import.
