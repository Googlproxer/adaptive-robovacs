# Adaptive RoboVacs v1.9.0

## Added

- Optional non-root Q10/B01 map-inspection controls for compatible Roborock
  runtimes. They request map data and show previews, but never import raw map
  files or start a clean.
- Read-only map-list and capture services, a per-robot map-capture status
  sensor, capture button, preview selector, and dashboard selection controls.
- A durable manual-verification scheduler hold around retained-map activation.
  It remains until manual relocalization and explicit mapping preflight have
  completed.

## Deployment notes

- The feature reuses Home Assistant's existing Roborock authentication and
  MQTT connection. It needs no root access, SSH, local broker, or second login.
- MapLoader remains out of scope because it requires filesystem access on the
  robot. This was never a raw-map import feature.

## Validation

- 206 unit tests passed.
- All integration Python modules compiled successfully.
- The integration-served and standalone dashboard JavaScript copies are byte
  identical.
