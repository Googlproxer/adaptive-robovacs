# Adaptive RoboVacs v1.6.1

Version 1.6.1 is a targeted recovery for scheduled Q10 two-pass cleaning.

- Before a scheduler occurrence starts, the integration validates its saved
  profile without mutating the vacuum.
- If that exact profile is no longer supported, it may be rebuilt from the
  current room and robot settings only when the occurrence is unstarted and
  the assigned robot is observed docked with no active job.
- Manual requests, running work, and robots away from the dock are never
  changed by this recovery. A profile that cannot be rebuilt remains a normal
  safe dispatch failure.
- The refreshed snapshot is persisted before dispatch, preserving restart-safe
  behaviour while allowing an already-pending room to use a newly corrected
  Q10 profile such as `max` instead of unsupported `max_plus`.

## Deployment notes

Install the exact `v1.6.1` tag through HACS and restart Home Assistant only
while both vacuums are idle. The first controlled test should use an unoccupied
room already pending on a docked Q10 vacuum. Confirm the custom profile write,
customized-mode selection, one native start, and observed cleaning state.
