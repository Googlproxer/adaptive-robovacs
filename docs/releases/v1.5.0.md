# Adaptive RoboVacs v1.5.0

Version 1.5.0 completes plan 5 and issue #4 with exact robot/room cleaning
profiles and safety-gated manual room actions.

## Cleaning profiles

- Vacuum cards retain robot defaults for cleaning program, fan speed, cleaning
  mode, mop mode, mop intensity, vacuum passes, and mop passes.
- Room cards add nullable **Robot default** overrides for the raw profile
  values advertised by eligible robots on that floor.
- Candidate assignment resolves the complete exact profile for every ordered
  stage. The selected adapter validates and reapplies it before dispatch, so
  controls from a prior room or stage cannot leak into the next clean.
- Store schema v7 persists the immutable stage profile and migrates existing
  rooms to inherited defaults. Stale values stay visible for diagnosis and
  block dispatch rather than being silently replaced.
- The existing room compatibility Repair now covers the program, independent
  pass counts, fan speed, cleaning mode, mop mode, and mop intensity.

## Manual room actions

- Every room card adds **Manual clean**, **Manual vacuum only**, and **Manual
  mop only** buttons. There is no hard-coded multipass action; each uses the
  room's current effective pass count.
- The new `adaptive_robovacs.manual_clean_room` action exposes the same path to
  scripts and Developer Tools with `area_id`, `mode`, and optional `entry_id`.
- Manual requests bypass only cadence and the desired cleaning window. They
  retain scheduler halt, Party/observe-only, occupancy, bedroom-transit,
  robot/battery, carpet, water confirmation, adapter/profile, mapping, and
  start-confirmation gates.
- Rejected presses are audited without creating latent work. Accepted ordered
  occurrences survive restarts, recheck every later-stage gate, and update the
  normal room cadence exactly once after physical completion.
- Existing external Home Assistant `vacuum.clean_area` observation remains
  `manual_home_assistant` and keeps its prior deferral behavior.

## Dashboard and migration

No card configuration changes are required. Existing room cards discover the
new profile selects and manual buttons automatically. The two dashboard module
copies remain byte-identical and continue hiding redundant room-name prefixes.

After installing `v1.5.0` through HACS, restart Home Assistant and verify each
robot default before selecting optional room overrides. An old room with no new
values displays **Robot default**. If a saved exact value later disappears,
resolve the room cleaning-profile Repair before scheduling resumes for it.

## Validation

The release is validated with 128 Python unit tests, Python compilation checks,
11 dashboard Node tests, dashboard-copy byte parity, and HACS icon byte parity.
