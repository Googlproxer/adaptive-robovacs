# Adaptive RoboVacs v1.8.1

Version 1.8.1 fixes a false scheduler fault observed when Roborock begins a
Mop stage by washing its mop at the dock.

- Only a discovered same-device Roborock detailed-status sensor reporting
  `washing_the_mop` confirms an accepted **Mop** stage. Vacuum stages and
  generic robots retain their existing start-confirmation rules.
- The active stage records durable `mop_washing` start evidence, cancels the
  raw-vacuum start watchdog, and stays in progress through the wash. It is not
  credited as a room clean until the ordinary observed cleaning lifecycle runs.
- Restart recovery preserves a Mop stage that is still washing, so a Home
  Assistant restart cannot discard it or create a false start fault.

## Validation

Run the full Python unit and compilation checks, plus the dashboard test,
before publishing the release.

## Deployment

Install the `v1.8.1` release through HACS. Restart Home Assistant only after
both vacuums are not cleaning or servicing. Existing scoped Repairs and pending
occurrences remain durable across the update.
