# Adaptive RoboVacs v1.21.1

Release date: 2026-11-06.

## Changes

The v1.21.0 deployment acceptance check found that robot occupancy attribution
remained unfiltered. Core 2026.11.0 pins python-roborock 7.12.0, whose Home trait
provides map update notifications; its map-content trait has no listener API.
The optional adapter had safely rejected that unsupported contract.

Bind to the existing Home-trait and coordinator notifications instead. Inspect
the cached parsed map by object identity, with no parsing, payload comparisons,
device queries or new polling. Only a replacement frame refreshes location age.
Ignore the Home trait's immediate cached subscription replay and unchanged
status/home notifications. Missing frames invalidate freshness. Registry numeric
mapping, occupancy classification and v1.20.3 persistence behavior are unchanged.

Tests now exercise the real pinned Home and map-content traits as well as the
synthetic contracts, including cached replay, expiry and listener cleanup. The
test environment explicitly pins the same native dependencies as Core.

## Migration and deployment

Requires Core 2026.11.0. There is no additional Store schema change beyond
schema 22 from v1.21.0. Rooms that first gain attribution still perform the
documented one-time vacancy-sample reset; cleaning records and other learning
remain intact. See the [migration guide](../migration-v1.21.0.md).

Install this exact release through HACS/Marketplace after CI succeeds. Validate
configuration and confirm both robots are idle before restarting Home Assistant.
After startup settling, verify attribution is active in supported mapped rooms
and genuine occupancy remains blocking. Normal startup does not prove movement
classification; live movement acceptance needs a subsequent observed robot visit.

## Validation

Local validation passed 691 pytest tests with 95.51% combined branch/line
coverage, 691 unittest tests, Ruff formatting/lint, strict mypy, top-level and
recursive compilation, 45 dashboard unit tests, ten browser regressions and
shipped-file parity. Two desktop touch tests are intentionally skipped. All
166 installed test-environment packages pass dependency compatibility checks.

The repeated 100-sample comparison against v1.20.3 passes cleaning budgets and
regression checks: active evaluation p95 is 58.05 ms and the 16-update timer
batch p95 is 254.84 ms. Attribution heartbeat/pulse p95 is 0.046/0.115 ms;
heartbeats add zero evaluations, saves or publications. See the
[performance documentation](../performance.md) for measured scope. No timing
result predicts live server CPU usage.
