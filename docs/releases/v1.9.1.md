# Adaptive RoboVacs v1.9.1

## Fixed

- Q10 retained-map capture now uses the raw response stream from Home
  Assistant's existing authenticated Roborock connection. The bundled Q10
  library otherwise parses map packets before the recovery guard can archive
  their original bytes.
- Typed Q10 DPS updates are normalised before extracting the retained-map list.
  This fixes map-list timeouts on Home Assistant 2026.8's bundled
  `python-roborock` runtime.
- The bounded map-frame parser now validates the documented big-endian width
  and height fields, rather than inferring grid height from room-like bytes.

## Deployment notes

- No robot configuration changes or cleaning commands are introduced. A map
  snapshot remains a docked/idle, read-only operation.

## Validation

- Unit tests cover the typed DPS list response and safe empty-message handling
  in addition to the existing map-bridge coverage.
