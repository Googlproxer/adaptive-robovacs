# Adaptive RoboVacs v1.12.0

## User-visible changes

- Adds `custom:adaptive-robovacs-floorplan`, a per-floor dashboard card for
  arranging discovered rooms, visualising direct room connections, and showing
  every discovered radar or fallback occupancy source.
- Home Assistant administrators can draw, move, resize, and link room
  rectangles, then place each sensor marker within its discovered room.
- Occupancy-source markers update from their current Home Assistant state and
  clearly distinguish active, inactive, and unavailable sources.

## Migration and safety

- Store schema v15 introduces an empty, restart-safe floor-plan document for
  existing installations. Room links use Home Assistant area IDs and sensor
  markers use entity-registry IDs; friendly-name and entity-ID changes do not
  invalidate the saved diagram.
- This release is configuration and visualisation only. It does not yet block
  a cleaning start because a directly linked room is occupied. Existing local
  occupancy, bedroom-transit, Party Mode, observe-only, and manual-clean rules
  are unchanged.
- `adaptive_robovacs.save_floor_plan` atomically saves one floor from an
  administrator dashboard draft. `adaptive_robovacs.set_room_adjacency` is the
  administrator script/Developer Tools counterpart for direct room links.
