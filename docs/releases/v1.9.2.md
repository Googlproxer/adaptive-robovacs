# Adaptive RoboVacs v1.9.2

## Fixed

- Retained-map slot discovery now keeps one response subscription open while
  sending the Q10's read-only `COMMON`/`MULTI_MAP` list request up to three
  times over a bounded 15-second window. Q10 cloud responses can arrive later
  than a single five-second request window.

## Safety and deployment

- The retry repeats only the robot's read-only map-list request. It never
  starts cleaning, changes the selected map, writes map settings, or creates a
  second Roborock connection.

## Validation

- Added coverage for a delayed map-list response that arrives after a retry.
