# Adaptive RoboVacs v1.11.2

## Fixed

- A return to dock no longer completes a room clean by itself. Roborock jobs
  now wait for the detailed `charging` or `charging_complete` status after
  docking, so an auto-empty cycle that resumes cleaning remains one job.
- Robots without detailed terminal status wait until both the predicted end and
  an uninterrupted five-minute dock dwell before their job is inferred complete.
- Restart recovery follows the same completion rules. Any job that crosses a
  Home Assistant outage is recorded for cadence with recovery confidence but is
  excluded from duration learning.

## Improved

- Learned room times now measure the full run from observed cleaning start to
  final dock arrival, including return and emptying time while excluding
  observed error and paused intervals.
- New verified samples provide a typical predicted total and a conservative
  required-vacancy duration, scoped by room, robot, operation, and pass count.
  Historical mixed-timing samples remain stored for audit but no longer train
  the new model.
- Room cards display both read-only duration values before the editable expected
  duration baseline.

## Validation and deployment

The release is covered by lifecycle, persistence, adapter, duration-model, and
dashboard regression tests, plus the complete Python compilation suite. Install
the exact HACS version and restart Home Assistant only after both vacuums are
idle.
