# Adaptive RoboVacs v1.5.1

Version 1.5.1 corrects operation-specific cleaning-profile validation found
during the live v1.5.0 deployment.

## Profile validation correction

- A vacuum stage now validates only its fan-speed and vacuum-mode controls.
- Retained mop-mode or mop-intensity values are ignored for vacuuming because
  those controls are neither applied nor relevant to that physical stage.
- Mop stages continue to validate the complete mop-relevant profile and still
  fail closed when an exact requested value is stale or unsupported.
- This clears false cleaning-profile Repairs for vacuum-only carpet rooms while
  preserving the exact-value and no-silent-substitution guarantees from
  v1.5.0.

No dashboard configuration or user setting migration is required. Store schema
remains v7.

## Validation

The release is validated with 129 Python unit tests, including a live-state
regression for retained mop-only values, Python compilation checks, 11
dashboard Node tests, dashboard-copy byte parity, and HACS icon byte parity.
