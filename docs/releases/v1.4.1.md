# Adaptive RoboVacs v1.4.1

Version 1.4.1 is a focused startup-discovery correction for the water-aware
cleaning controls introduced in v1.4.0.

## Fixes

- Cleaning-program selectors now derive their options from current adapter
  capabilities instead of retaining the capability snapshot from entity setup.
- Same-device vendor profile selects are watched even when their options load
  after Adaptive RoboVacs' first discovery pass.
- Room program and mop-pass controls now appear as soon as a late-loading
  mop-capable vacuum is discovered, without another Home Assistant restart.

## Validation and deployment

The complete Python and frontend contract suites pass, including a regression
test for dynamic program options and capability-source refresh. Install
`v1.4.1` through HACS and restart Home Assistant. No Store migration or entity
ID change is introduced beyond v1.4.0.
