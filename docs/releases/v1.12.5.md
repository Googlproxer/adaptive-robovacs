# Adaptive RoboVacs v1.12.5

## User-visible changes

- `robovac-exclude-occupancy` is a device-only label. Every motion or
  occupancy binary sensor owned by a labelled device is excluded from room
  occupancy tracking.
- Device label updates refresh discovery immediately, removing newly excluded
  sources without waiting for the scheduler's next interval.

## Migration and safety

- No durable floor-plan, scheduler, occupancy, or cleaning data changes.
- Apply the label to a device such as an outside-facing doorbell; do not apply
  it to individual sensor entities.

## Validation

- `python -m unittest discover -s tests -v`
- Python compilation of every integration module
