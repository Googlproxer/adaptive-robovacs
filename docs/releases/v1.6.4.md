# Adaptive RoboVacs v1.6.4

Version 1.6.4 adds Q10 custom-clean support for the native **Max+** fan-speed
value.

- A Q10 custom profile now encodes Max+ as protocol fan level `8`.
- If the robot rejects a Max+ custom-profile write or room-start command, the
  effective robot or room fan-speed setting is changed to **Max**. The clean
  is not retried automatically.
- If an accepted Max+ start does not confirm, the setting is likewise changed
  to Max while the existing scheduler safety halt handles the uncertain clean.

## Validation

The release candidate must pass the Python unit suite, integration
compilation, dashboard Node tests, and dashboard byte-parity check.

## Deployment notes

Install the exact `v1.6.4` tag through HACS and restart only while both
vacuums are idle. Test one safe, unoccupied mapped room with a Fast,
one-pass, Max+ manual vacuum clean. Confirm the robot enters cleaning and the
adapter reports no custom-profile write failure.
