# Adaptive RoboVacs v1.3.1

## User-visible change

- Fixed vendor controls, including fan-speed selections, sometimes not appearing
  when the vacuum published its capabilities after Adaptive RoboVacs' entity
  platforms had initialized.

## Upgrade notes

This is a corrective patch for v1.3.0. It changes no entity IDs, unique IDs,
stored settings, scheduler decisions, adapter commands, or dashboard
configuration. Update through HACS and restart Home Assistant once both vacuums
are idle.
