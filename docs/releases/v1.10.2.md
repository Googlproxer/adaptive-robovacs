# Adaptive RoboVacs v1.10.2

## Dashboard simplification

The room card no longer displays its **Enabled** or **Ignore desired cleaning
window** toggles. Use **Cleaning period** to enable or disable room scheduling:
**Off** disables it, while **Default**, named periods, and **Custom** enable
it.

Both switches retain their existing public entity IDs and behavior for existing
automations and advanced Home Assistant use. The Ignore desired cleaning window
switch continues to be subject to all occupancy, bedroom-transit, Party Mode,
and observe-only safety rules.

## Validation and deployment

Validated with the complete Python unit suite, dashboard tests, integration
module compilation, and a byte-for-byte dashboard-copy check. Install this
release through HACS and restart Home Assistant after both vacuums are idle.
