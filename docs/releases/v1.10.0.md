# Adaptive RoboVacs v1.10.0

## Added

- Each room has a **Cleaning period** selector with Off, Night, Morning,
  Afternoon, Evening, and Custom options. Named periods translate into the
  existing room enablement and desired-window settings; no alternate scheduler
  path is introduced.
- Each room has a **Cleaning profile** selector. **Robot default** clears all
  room-owned program, pass, fan, mode, mop, and cleaning-depth overrides.
  **Custom** preserves the saved values and exposes their existing controls on
  the room card.

## Migration

- Durable scheduler state is schema v12. Existing rooms that already save one
  or more profile overrides migrate to **Custom**, retaining every value and
  their effective cleaning behavior. Other rooms begin at **Robot default**.
- No existing public entity ID or unique ID changes. Detailed room controls
  remain published for automations even when the dashboard hides them under
  Robot default.

## Validation

- Added pure scheduling-period and room-profile transition tests, v11-to-v12
  Store migration coverage, and card visibility tests. The integration-served
  and standalone dashboard scripts remain byte-identical.
