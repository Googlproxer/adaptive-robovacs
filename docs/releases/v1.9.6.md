# Adaptive RoboVacs v1.9.6

## Changed

- Renamed the experimental Q10 controls and dashboard labels to **map
  inspection**, **map capture**, and **map selection**. The release-hold service
  is now `adaptive_robovacs.confirm_map_selection`.
- The documentation now explicitly states the limitation: this interface
  cannot duplicate, preserve, import, or restore robot maps. A returned map
  capture is for inspection only.

## Migration

- Replace automations that called
  `adaptive_robovacs.verify_map_recovery` with
  `adaptive_robovacs.confirm_map_selection` using the same fields.
- Existing entity unique IDs and the private durable-storage key are retained
  for Home Assistant continuity. Their visible names no longer use the removed
  terminology.

## Validation

- Updated the service contract and verified that the integration-served and
  standalone dashboard copies remain byte-identical.
