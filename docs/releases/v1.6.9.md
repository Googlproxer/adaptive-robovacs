# Adaptive RoboVacs v1.6.9

## Scheduler-halt recovery

- A docked vacuum can now clear a stale scheduler halt even when its battery is
  below the configured minimum. Battery, occupancy, profile, adapter, and map
  checks remain in force when the scheduler later considers a new clean.
- The scheduler-halt Repair now reports the exact safe reason it could not
  clear, including an unavailable robot state, missing recovery target, or a
  vacuum that is neither docked nor cleaning.
- A vacuum already cleaning still clears the halt without interrupting the
  physical clean or crediting an unconfirmed room.

## Validation and deployment

- Validated with the full unit suite and Python compilation checks.
- Install this exact release through HACS and restart Home Assistant.
