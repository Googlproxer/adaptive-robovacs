# Adaptive RoboVacs v1.11.1

## Fixed

Radar occupancy discovery now uses a radar device's labels when an occupancy
binary sensor has no direct labels of its own. This allows a single
`robovac-radar` device label to classify its radar entities without adding the
label to every entity.

Direct entity labels remain authoritative. Assign a direct label to an entity
when it must not inherit its device's radar classification.

## Validation and deployment

The release is covered by regression tests for both device-label inheritance
and direct entity-label precedence, as well as the complete Python unit and
compilation checks. After release, install the exact HACS version and restart
Home Assistant while both vacuums are idle.
