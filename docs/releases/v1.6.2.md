# Adaptive RoboVacs v1.6.2

Version 1.6.2 adds **Cleaning Depth** controls for compatible Roborock Q10
custom room cleaning.

- Eligible Q10 robots expose robot-default and room-override controls with
  Fast, Daily, and Fine options.
- Q10 defaults remain one pass with Daily depth. Rooms can independently use
  Fast, Daily, or Fine with either one or two vacuum passes.
- A selected depth is encoded into the immediate Q10 custom profile before the
  single physical room-clean start. The integration still selects
  `customized` mode for every such start and never relies on profile
  persistence.
- Q10 custom profiles continue to reject `max_plus` safely. Other vacuums do
  not expose the control and cannot silently discard a saved depth override.
- Existing persisted state remains compatible; profiles without an explicit
  depth retain the established Daily Q10 encoding.

## Validation

The release candidate passed the Python unit suite, integration compilation,
the dashboard Node tests, and byte-parity checks for the served and standalone
dashboard cards.

## Deployment notes

Install the exact `v1.6.2` tag through HACS and restart Home Assistant only
while both vacuums are idle. Confirm the new Q10 Cleaning Depth controls are
available, then test one unoccupied mapped room with the default Daily profile
and one non-default depth. Verify normal observed cleaning and completion
state transitions after each start.
