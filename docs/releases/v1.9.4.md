# Adaptive RoboVacs v1.9.4

## Fixed

- Q10 map-frame validation no longer mistakes bytes 25–26 of the wire header
  for a declared decompressed-layout length. The current Home Assistant
  Roborock decoder treats those bytes as opaque, and genuine current-firmware
  frames need not match that assumption.

## Safety and capability

- The parser remains bounded to 512 KiB packets and one million grid cells.
  It still validates the map marker, dimensions, compressed-block bounds, LZ4
  back-references, and room-record bounds, and preserves the complete raw
  packet unchanged.
- Capture still sends no map-selection, clean, deletion, or map-edit command.

## Validation

- Added coverage for a valid map packet with a zero opaque header field.
