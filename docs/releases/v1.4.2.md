# Adaptive RoboVacs v1.4.2

Version 1.4.2 completes the startup-discovery correction for the water-aware
cleaning controls introduced in v1.4.

## Fix

- Adaptive RoboVacs performs one dry-run capability refresh 30 seconds after
  initialization. This discovers Roborock mode entities whose initial state
  transition occurred before the integration registered its entity watchers.
- The refresh updates controls and diagnostics only. It cannot dispatch a clean
  and does not alter vacuum settings.

## Validation and deployment

The complete Python and frontend contract suites pass, including regressions
for live program options, profile-entity watches, and the bounded post-start
refresh. Install `v1.4.2` through HACS and restart Home Assistant. No Store
migration or entity ID change is introduced beyond v1.4.0.
