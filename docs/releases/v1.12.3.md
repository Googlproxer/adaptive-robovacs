# Adaptive RoboVacs v1.12.3

## User-visible changes

- Add the `robovac-exclude-occupancy` label for a motion or occupancy binary
  sensor that must not contribute to its room's occupancy state.
- The label can be applied directly to the sensor or to its device. A
  device-level label excludes all of that device's motion and occupancy
  entities, including entities that carry other direct labels.

## Migration and safety

- No durable floor-plan, scheduler, occupancy, or cleaning data changes.
- Apply `robovac-exclude-occupancy` to an Entry doorbell device to suppress
  its outside-facing motion sensor without excluding the Entry room itself.

## Validation

- `python -m unittest discover -s tests -v`
- Python compilation of every integration module
