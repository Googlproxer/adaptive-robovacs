# Adaptive RoboVacs v1.9.3

## Fixed

- Q10 map-frame archival now triggers the active map with the firmware's
  read-only direct `MULTI_MAP` list command, followed by a normal status
  refresh. The response is the raw protocol-301 frame and must still match the
  retained map identifier before it can be saved.

## Safety and capability

- No map is selected, deleted, renamed, or edited; no clean is started. The
  operation is only available while the robot is docked or idle.
- The active map can be archived safely. A robot that retains additional,
  inactive maps but cannot return their raw frames without selecting them is
  reported as incomplete rather than silently saving a partial set.

## Validation

- Updated bridge coverage to assert that active-map capture uses the direct,
  read-only request and retains subscription cleanup.
