# Adaptive RoboVacs v1.22.0

Release date: 2026-11-09.

## Changes

Exclude new occupancy detections in confirmed cleaning rooms until observed
docking. Known dispatched jobs provide room identity even when a robot has no
compatible native location source. External cleans use supported fresh room
evidence; future queued rooms and unknown external rooms receive no exemption.

At docking, re-read the selected sensors even when their state never changed.
Clear rooms retain valid vacancy continuity; occupied rooms begin a blocking
episode at docking. Give the robot's registry-assigned home room a further
three-minute sensor cooldown, then perform the same check from cooldown expiry.
Handle overlapping robots, direct docking, intermediate docks and immediate
new departures without extending an old cooldown on status heartbeats.

Preserve established human occupancy, mode gates, final dispatch revalidation
and conservative sensor, interruption and restart behavior. Keep active sessions
and cooldowns as explicit room and adjacency blockers. No new robot queries,
map parsing, recorder queries or periodic polling are introduced.

## Migration and validation

Store schema 22 migrates to 23. Affected rooms retire older vacancy samples once
on first session coverage; cleaning records and other learning remain intact.
Startup never restores a vacancy anchor across downtime. See the
[migration guide](../migration-v1.22.0.md).

The validation environment targets Core 2026.11.0 and Python 3.14.10. The live
Core version and [official stable feed](https://raw.githubusercontent.com/home-assistant/version/master/stable.json)
were checked on 2026-11-09; both report 2026.11.0. Existing native dependency pins
match [that Core's manifest](https://github.com/home-assistant/core/blob/2026.11.0/homeassistant/components/roborock/manifest.json), and other
pinned validation tools and official Action major versions remain current.
No live Core upgrade is part of this change.

Local validation passes 722 pytest tests with 95.52% combined branch/line
coverage, 835 subtests, 722 unittest tests, Ruff formatting/lint, strict mypy,
top-level and recursive compilation, dependency compatibility checks and shipped
file parity. All 45 dashboard tests and ten applicable browser regressions pass;
two desktop touch tests are intentionally skipped. The local runtime and CI
pin use Python 3.14.10; Home Assistant's upstream HTTP deprecation warning is the
only pytest warning.

The matched 100-sample performance comparison and active-session heartbeat
invariants pass. See [the measurements](../performance.md) for workload, timings
and scope. No live CPU or hardware behavior is inferred from these offline runs.
