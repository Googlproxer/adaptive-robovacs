# Adaptive RoboVacs v1.6.8

## Scheduler-halt recovery

- A scheduler-halt Repair can now clear when the affected vacuum is already
  observed cleaning. The active clean is never interrupted.
- When Home Assistant cannot prove which room that clean belongs to, Adaptive
  RoboVacs treats it as native-app activity. It does not mark the planned room
  as cleaned, learn a duration, or change its cadence.
- The robot status exposes this untracked state as `native_app_assumed`.

## Validation and deployment

- Validated with the full unit suite and Python compilation checks.
- Install this exact release through HACS and restart Home Assistant.
