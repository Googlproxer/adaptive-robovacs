# Adaptive RoboVacs v1.6.3

Version 1.6.3 corrects the initial Q10 Cleaning Depth default.

- Existing Q10 robot profiles that predate the setting now initialize to
  **Daily** depth, as intended.
- One pass remains the default; rooms still inherit the robot default and can
  independently override either pass count or Cleaning Depth.
- An intentional later **Not configured** selection stays unset instead of
  being overwritten during a restart.

## Validation

The release candidate passed the Python unit suite, integration compilation,
the dashboard Node tests, and byte-parity checks for the served and standalone
dashboard cards.

## Deployment notes

Install the exact `v1.6.3` tag through HACS and restart Home Assistant only
while both vacuums are idle. Confirm the Q10 robot Cleaning Depth control now
shows Daily and a room override shows Robot default before testing a clean.
