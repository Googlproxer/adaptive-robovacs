# Adaptive RoboVacs v1.6.5

## Manual room-clean override

- Dashboard room-clean requests now bypass scheduler cadence, desired windows,
  room occupancy and vacancy forecasting, bedroom-transit restrictions,
  configured enablement, battery thresholds, scheduler holds, and scheduler
  dispatch halts.
- A manual request requires a discovered compatible robot on the room's floor
  that is physically docked. Party Mode and observe-only mode remain
  non-bypassable safeguards.
- The override is retained in the stored occurrence so configured multi-stage
  manual cleans keep the same behaviour after restart.
