# Adaptive RoboVacs v1.12.4

## User-visible changes

- Includes `robovac-exclude-occupancy`, which excludes an outside-facing or
  otherwise unsuitable motion/occupancy sensor from its room's occupancy
  calculation. Apply it to the sensor or its owning device.

## Migration and safety

- No durable floor-plan, scheduler, occupancy, or cleaning data changes.
- `v1.12.3` is superseded by this release and should not be installed.

## Validation

- The release metadata check now validates the required semantic-version
  format without pinning a specific release number.
- `python -m unittest discover -s tests -v`
- Python compilation of every integration module
