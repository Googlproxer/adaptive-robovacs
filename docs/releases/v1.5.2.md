# Adaptive RoboVacs v1.5.2

Version 1.5.2 removes the redundant **Manual request** status row from room
cards.

- Completed manual actions already update **Last cleaned** and become the
  room's normal cadence anchor.
- Rejected and accepted requests remain available in the backend audit state
  for diagnostics, but that audit is no longer presented as an everyday room
  status.
- The three **Manual clean**, **Manual vacuum only**, and **Manual mop only**
  actions remain unchanged.
- Existing dashboard configuration and saved settings require no migration.

## Validation

The release is validated with 129 Python unit tests, Python compilation checks,
11 dashboard Node tests, dashboard-copy byte parity, and HACS icon byte parity.
