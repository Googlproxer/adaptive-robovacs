# Adaptive RoboVacs v1.3.2

## User-visible change

- Fixed blank Home Assistant Repair dialogs. Scheduler-failure and two-pass
  compatibility Repairs now show their translated title, diagnostic context,
  confirmation instructions, and failed-recheck message.

## Upgrade notes

This is a corrective patch for v1.3.0 and v1.3.1. It changes no scheduler
decisions, adapter commands, entity IDs, unique IDs, stored settings, or
dashboard configuration. Existing Repair issues remain active across the
upgrade and display their content after Home Assistant restarts.

- Dashboard Node contract suite.

- Home Assistant configuration validation, exact HACS release installation,
