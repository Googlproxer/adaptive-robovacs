# Adaptive RoboVacs v1.6.11

## Mop-only enforcement

- Mop-only starts now prefer the robot's explicit **Mop only** option when it
  is advertised.
- Before every physical mop stage, Adaptive RoboVacs applies the complete
  stage profile, then confirms the operation selector reports Mop-only. It
  retries for up to 30 seconds and does not send a room-clean command until
  confirmation succeeds.
- When confirmation fails, the scheduler skips only the mop stage with a safe
  diagnostic outcome. A completed vacuum stage in a **Vacuum then mop**
  program remains completed and is never repeated.
- Shared operation/mop selectors are applied only once, with the stage
  operation selector winning. This prevents a combined vacuum-and-mop option
  from overwriting Mop-only.

## Validation and deployment

- Run the full unit and Python compilation checks before installing.
- Install this exact release through HACS. Confirm both vacuums are not
  cleaning, then restart Home Assistant and verify the integration loads.
