# Adaptive RoboVacs v1.7.2

## Dashboard responsiveness

- Global, vacuum, and room cards now collect Home Assistant updates into one
  animation-frame flush. While the browser tab is hidden, each card retains
  only the newest state snapshot and resumes with that state when foregrounded.
- One shared index discovers Adaptive RoboVacs entities by integration entry,
  robot, and room. Cards no longer rescan every Home Assistant entity or
  recreate their native `entities` card for unrelated updates.
- A row-state change updates the existing native card. A rebuild happens only
  when the card's own entry selection, target, title, visible controls, or
  optional mopping summary row changes.
- Existing card types, configuration, dynamic entity discovery, public entity
  IDs, confirmation actions, and displayed failure diagnostics are unchanged.

## Coordinator publishing

- A scheduler evaluation now refreshes discovery without first publishing an
  intermediate entity state. It sends its normal final notification after the
  preview and observed scheduler projection are current.
- Global, room, and robot setting changes likewise rely on their immediately
  following dry evaluation for the final notification.
- Direct discovery refreshes retain their immediate notification. Observed
  robot transitions, occupancy blocks, scheduler locking, and per-dispatch
  safety rechecks are unchanged.

## Validation and deployment

- Dashboard tests cover hidden-tab coalescing, unaffected native-card updates,
  in-place row refreshes, structural discovery rebuilds, helper reuse, and
  disconnected-card races.
- Run the complete unit suite, Python compilation, dashboard syntax checks,
  and served/standalone dashboard-copy parity before publishing.
- Install the exact `v1.7.2` tag through HACS only when both vacuums are
  idle, then restart Home Assistant and verify that the integration loads and
  the dashboard shows the newest observed state.
