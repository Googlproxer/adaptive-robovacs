# Adaptive RoboVacs v1.12.2

## User-visible changes

- The Floor plan editor labels every occupancy source with its existing Home
  Assistant friendly name. It no longer generates ambiguous labels such as
  `Entry Fallback`.
- Hovering a placed marker shows `{sensor name}: {state}`, where the state is
  `active`, `inactive`, or `unavailable`.

## Migration and safety

- No durable floor-plan, scheduler, occupancy, or cleaning data changes.

## Validation

- `python -m unittest discover -s tests -v`
- Python compilation of every integration module
- `node --check` and `node --test tests/test_dashboard.mjs`
- Confirmed served and standalone dashboard JavaScript copies are byte-identical.
