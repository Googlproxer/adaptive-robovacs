# Adaptive RoboVacs v1.22.1

Release date: 2026-11-16.

## Changes

Rooms with unavailable occupancy sensors could pass the scheduler's existing
desired-window policy, then be rejected by managed-run admission with
"queued room vacancy: room is not clear". Once battery learning enabled managed
runs, these rooms could remain overdue indefinitely.

Use the same unresolved-occupancy window policy for run admission, queue
revalidation and forecast previews. Check live occupancy and the current window
again instead of trusting an earlier candidate's permission. Every projected
stage must also start inside the desired window when occupancy is unresolved,
even if Ignore desired cleaning window is enabled. Occupied rooms and unresolved
neighbours remain blocking; battery, Party Mode, observe-only, dispatch and
restart-recovery checks retain their existing authority.

## Migration and validation

No Store migration, entity-ID changes or settings reset is required. Schema 23,
cleaning records, due times, learned durations and battery learning are retained.
The existing v1.22.0 migration guide still applies when upgrading older versions.

Checked the live Core version and the
[official stable feed](https://raw.githubusercontent.com/home-assistant/version/master/stable.json)
on 16 November: both report 2026.11.1. Refresh the test environment to that Core
patch and Ruff 0.17.5. Python remains 3.14.10; native Roborock pins still match
[Core's manifest](https://github.com/home-assistant/core/blob/2026.11.1/homeassistant/components/roborock/manifest.json).
Other explicit test pins and official Action major versions remain current.
No Core upgrade is part of this release.

Local validation passes all 727 pytest and unittest tests with 95.54% combined
branch/line coverage, Ruff formatting/lint, strict mypy, top-level and recursive
compilation, dependency compatibility and dashboard/icon byte parity. All 45
dashboard unit tests and ten applicable Chromium/mobile/WebKit browser
regressions pass; two desktop touch cases are intentionally skipped. Pytest
reports the upstream Home Assistant HTTP deprecation and a local cache-path
warning; neither affects test execution or production behavior.
