# Adaptive RoboVacs v1.10.1

## Fixed

- Room-card **Cleaning period** and **Cleaning profile** now appear immediately
  after Occupancy. Detailed profile controls remain hidden unless Cleaning
  profile is **Custom**, and detailed Desired start/end controls remain hidden
  unless Cleaning period is **Custom**.
- **Cleaning period** now includes **Default**. It enables the room and clears
  both room Desired bounds so the global Desired start and end apply. Rooms
  that already inherit both bounds display Default without a Store migration.

## Validation

- Added period-default model coverage and dashboard visibility/order coverage
  for default, custom, and temporarily unavailable selector entities. The
  integration-served and standalone dashboard scripts remain byte-identical.
