# Adaptive RoboVacs v1.6.6

## Stop and return to dock

- Added a **Stop and return to dock** button to every discovered robot card.
  It sends the robot's native return-to-base command.
- A tracked scheduled or manual clean is marked as cancelling immediately and
  remains so until the robot is observed docked. The interrupted work is not
  recorded as a completed clean.

## Room mopping controls

- Removed the room **Carpet (no mopping)** toggle. Rooms now use their explicit
  cleaning program and per-room mop controls to determine whether mopping runs.
- Store schema v8 discards legacy carpet settings, preventing an old hidden
  value from silently blocking a configured mop stage.

## Validation

- `python -m unittest discover -s tests -v`
- Python compilation for the integration modules
- Dashboard test suite and served/standalone dashboard parity check
