# Adaptive RoboVacs 1.11.5

## Fixed

- Scheduled Roborock room preflight now reads the vacuum's live cleanable
  segments when a Home Assistant area mapping needs checking.
- Only mappings for segment IDs absent from a complete, valid response are
  removed. The scheduler never selects a replacement target from a segment
  name, and it does not alter mappings when live evidence is empty, malformed,
  or unavailable.
- A refreshed mapping blocks only the affected room and creates the existing
  non-dispatching **Recheck** Repair. Submitting the Repair validates the
  revised mapping without starting a clean; the next normal scheduler cycle
  remains subject to all usual safety gates.

## Validation and deployment

Run the complete unit suite and Python compilation checks before release. Install
the exact HACS version and restart Home Assistant only after both vacuums are
idle.
