# Adaptive RoboVacs v1.7.3

Version 1.7.3 fixes a scheduler deferral bug.

- Stale restored deferrals and deferrals produced by a floor-cancellation
  rebase can no longer postpone a room past one configured cleaning cadence.
- Short manual-clean and cancellation cooldown deferrals within the cadence
  horizon retain their existing behaviour.
- Existing scheduler history and configuration require no migration.

## Validation

Validated with 184 Python unit tests and Python compilation checks for every
integration module.

## Deployment

Install the `v1.7.3` release through HACS, then restart Home Assistant when
both vacuums are not cleaning. The integration will recalculate each room's
next due time from its saved history and cadence after loading.
