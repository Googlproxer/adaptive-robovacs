# Adaptive RoboVacs v1.12.7

## User-visible changes

- Connection and resize handles disappear after finishing or cancelling a
  floor-plan edit. Sensor markers use the default cursor in view mode and the
  move cursor only while editing.
- Room connections now attach at the closest two room boundaries. Where a
  straight route is not possible, the connection uses a 45-degree diagonal and
  one horizontal or vertical segment, keeping the plan grid-aligned.

## Migration and safety

- No durable floor-plan, scheduler, occupancy, or cleaning data changes.

- `python -m unittest discover -s tests -v`

- `node --check custom_components/adaptive_robovacs/frontend/adaptive-robovacs-dashboard.js`
